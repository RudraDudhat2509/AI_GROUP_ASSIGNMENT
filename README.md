# AI Group Assignment 1

Solutions to Group Assignment 1 (AI course, Sept 2026). Four problem statements,
each in its own folder with a standalone script and a notebook walking through
the build.

## Problem Statements

- **ps1_rescue_robot** - BFS and DFS pathfinding on a grid
- **ps2_campus_search** - Greedy Best-First Search and A* on a weighted graph
- **ps3_robot_battle** - Minimax and Alpha-Beta pruning for a 2-robot game
- **ps4_exam_timetable** - Hill Climbing for exam timetable optimization

Each folder has:
- `<name>.py` - standalone script matching the spec's stdin/stdout format
- `<name>.ipynb` - notebook showing the build process and sample test verification
